📖 دليل أوامر VEXcode VR المتاحة

يدعم هذا المحاكي جميع أوامر VEX VR Python الأساسية المتوافقة مع المناهج التعليمية:

الجهاز / الفئة الدالة والمثال في بايثون الوصف والتأثير
Drivetrain (التحكم بالحركة) drivetrain.drive_for(FORWARD, 200, MM)
drivetrain.drive_for(REVERSE, 150, MM)
drivetrain.turn_for(RIGHT, 90, DEGREES)
drivetrain.drive(FORWARD) / stop()
drivetrain.set_drive_velocity(80, PERCENT) 		التحرك للأمام أو الخلف بمسافة محددة، أو الدوران بزاوية، والتحكم بالسرعة.
Pen (قلم الرسم) pen.move(DOWN) / pen.move(UP)
pen.set_pen_color(BLACK / RED / GREEN / BLUE)
pen.set_pen_width(5) 		إنزال القلم لرسم المسار أو رفعه، وتغيير ألوان الرسم على أرضية الملعب.
Distance Sensor (المسافة) distance.get_distance(MM)
distance.found_object() 		قراءة المسافة للأمام مقدرة بالملم، والتحقق من وجود حواجز أو جدران.
Bumper Sensor (الصدام) left_bumper.pressing()
right_bumper.pressing() 		يرجع True عند اصطدام مقدمة الروبوت بأي جدار.
Magnet (المغناطيس) magnet.energize(BOOST)
magnet.energize(DROP) 		تشغيل المغناطيس لالتقاط الأقراص المعدنية أو إيقافه لإفلاتها.
Down Eye Sensor (حساس الألوان) down_eye.detect(RED / GREEN / BLUE) الكشف عن لون البلاطة أو القرص الموجود تحت مقدمة الروبوت مباشرة.
الوقت والطباعة wait(1, SECONDS)
print("نص للتتبع...") 		إيقاف مؤقت، وطباعة القيم في شاشة الـ Console المدمجة.
